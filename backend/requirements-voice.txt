# Optional local voice pipeline (offline; no API keys).
#
# None of these are required to run SPRYGEN — the app starts without them and
# the voice features fail closed with a clear "not installed" message. Install
# them only if you want wake-word listening, speech-to-text, the speaker lock,
# and local text-to-speech:
#
#   pip install -r backend/requirements-voice.txt
#
# The core subset (capture + wake word + speech-to-text) lives in
# `requirements-voice-core.txt` and is bundled into packaged builds; this file
# adds the PyTorch-based extras:
#
#   * resemblyzer — speaker voiceprint (the speaker lock)
#   * kokoro      — fully local text-to-speech
#
# See THIRD_PARTY.md for the licenses of these components.
-r requirements-voice-core.txt
